The work being built is described in the envelope: read it before starting.

Your design surface is the directory the `design` quality check scans. Find
it in `adws/config/sssf.config.yaml`: the check named `design` declares its
`surface` (the detect target in its argv). If PRODUCT.md exists at the repo
root, read it first — it is your design context.

The phase directive names the pass to run. Apply every actionable fix each
impeccable command reports, and report the files you changed in your
envelope.
